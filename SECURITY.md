# Alcance de seguridad

Los componentes de `examples/vulnerable` son intencionalmente inseguros y no forman parte del sitio publicado. El servidor de desarrollo solo entrega una lista explícita de archivos de `app/`.

Los escáneres operan sobre este repositorio propio. Cero hallazgos significa que las reglas ejecutadas no reportaron problemas en el alcance analizado, no que la aplicación sea invulnerable. La app no proporciona autenticación, cifrado de notas ni sincronización.
